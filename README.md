## Tecnologias Utilizadas
- ASP.NET Core 8.0 / C#
- Entity Framework Core
- SQLite (banco de dados)
- Bootstrap 5 (front-end)

## Como Rodar
1. Clone o repositório
2. Abra a pasta no VS Code
3. No terminal: dotnet restore
4. No terminal: dotnet ef database update
5. No terminal: dotnet run

## Funcionalidades
- Cadastro e login de usuários
- Catálogo de filmes com cartaz, sinopse, diretor e ano
- Avaliação de filmes com nota (1-10) e comentário
- Crítica do editor
- CRUD completo de filmes e avaliações
